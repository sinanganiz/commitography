# ADR-0046: Canonical path containment and product-controlled clone targets

**Status:** Accepted

## Context
The allowed-root mechanism exists but its semantics were never written down.
Prefix comparison is the classic error: one root string is a prefix of an
unrelated sibling directory, and a symbolic link inside a root can point
anywhere. Working tree content is untrusted (ADR-0045), so links encountered
during analysis are equally hostile.

## Decision
1. Every path MUST be canonicalised and its symbolic links resolved before
   containment is checked. Containment MUST be evaluated at directory
   boundaries. String prefix comparison MUST NOT be used.
2. During working tree traversal, symbolic links leading outside the containing
   root MUST NOT be followed. Affected paths MUST be recorded as skipped with a
   reason per ADR-0032.
3. **Clone target directories MUST be generated by the product.** They MUST NOT
   be derived from the URL, the repository name, or any user-supplied value.
   Repository names are display data only.
4. Output paths MUST pass the same validation as input paths.
5. The analysed repository MUST NOT be written to under any circumstance. A
   read-only mount MUST be the documented recommendation.
6. Process-level sandboxing MUST NOT be implemented in the product, because it
   would break cross-compilation and the single-binary guarantee (ADR-0022).
   Isolation is delegated to the container and documented as the recommended
   deployment.

## Consequences
- Path traversal through crafted names or links is prevented at one layer rather
  than at each call site.
- A hostile repository cannot direct writes outside a generated target.
- Deployment documentation carries the isolation recommendation rather than the
  binary carrying platform-specific code.

## Out of scope
- Operating-system sandboxing primitives inside the product.

## Assumption
Canonicalisation semantics are consistent enough across supported platforms to
be expressed behind one interface.

## Acceptance criteria
- A root whose name is a prefix of a sibling directory does not admit that
  sibling.
- A repository containing a symbolic link escaping the root produces a skipped
  entry, not a traversal.
- Clone targets contain no attacker-influenced path segment.

## Dependencies
ADR-0045 must be implemented before this one.
